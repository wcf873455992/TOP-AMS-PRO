# TOP AMS PRO

> 基于 ESP32-C3 的第三方多色耗材管理系统，为 Bambu Lab P2S 打印机提供外置换料支持。

---

## 一、项目简介

TOP AMS PRO 是一套运行在 ESP32-C3 上的第三方多色耗材管理系统，为 Bambu Lab P2S 打印机提供外置换料支持。通过监听打印机 MQTT 状态，配合 DRV8833 电机驱动完成物理进退料，实现多通道耗材自动切换。

MQTT 通讯协议参考了 Top-AMS 项目的实现，采用相同的主题结构和认证方式。

| 项目 | 信息 |
|------|------|
| 主控 | ESP32-C3 |
| 开发框架 | ESP-IDF v6.1.1 |
| 电机驱动 | DRV8833 |
| 目标打印机 | Bambu Lab P2S |
| 通信方式 | MQTT over TLS（8883） |
| 配网方式 | AP 热点 + 网页配网 |
| OTA 升级 | 网页升级 |

## 二、使用说明

首次上电配网

1. 给 ESP32-C3 上电，等待 3~5 秒
2. 手机或电脑搜索 WiFi 热点：TOP AMS PRO（无密码）
3. 连接后浏览器访问：http://192.168.1.1
4. 点击「配置 WiFi」→ 页面自动扫描附近路由器
5. 选择家庭 WiFi → 输入密码 → 提交
6. 连接成功后，ESP32 切换到 STA 模式，热点自动关闭
7. 记录串口日志里的 STA IP，或从路由器管理界面查找 ESP32 的新 IP
8. 之后同一 WiFi 下访问 http://<新IP>/ 即可

配置打印机

1. 打印机屏幕：设置 → 网络 → 网络详情，记录：
   - 打印机 IP（如 192.168.1.100）
   - 设备序列号 SN（如 22E8B******01757）
   - 访问码 Access Code（8 位数字）
2. 浏览器访问 ESP32 主界面 → 点击「配置打印机」
3. 填入 IP / SN / Access Code → 点击「保存并连接」
4. 主界面「打印机状态」显示「已连接」→ 配置成功

设置耗材通道

1. 主界面「耗材通道」区域，每个通道可设置：
   - 材料类型：PLA / PETG / ABS / TPU / ASA / PC / PA / PVA / HIPS
   - 颜色：点击圆形色块，从预设或自定义选色
   - 进料时长：GPIO 拉高毫秒数，默认 6000ms
   - 退料时长：GPIO 拉高毫秒数，默认 5000ms
2. 修改后自动保存到 NVS

选择工作模式

| 模式 | 特点 | 适用场景 |
|------|------|---------|
| 被动模式（默认） | 只读打印机状态 + 本地 GPIO 进退料 | 普通用户，无需改打印机设置 |
| 主动模式 | 主动发 MQTT 命令 + 本地 GPIO | 需打印机开「仅局域网 + 开发者模式」 |

切换方式：主界面 → 耗材通道标题栏右侧 →「被动模式 / 主动模式」按钮。

被动模式限制：切片文件触发 M400 U1 或 M620 时，打印机会暂停等用户确认，需在打印机屏幕上手动点「继续」才能恢复打印。

主动模式要求：打印机需开启「仅局域网模式 + 开发者模式」，且手机 App（Bambu Handy）将不可用。

手动换料操作

主页每个通道有 3 个按钮：

| 按钮 | 功能 |
|------|------|
| 进料 | 从该通道推送耗材到挤出机 |
| 退料 | 从挤出机退回该通道的耗材 |
| 装载 | 退当前料 + 进目标料（一键换料） |

进料按钮行为（主动模式）：
1. 等待 ams_status 变为 261（送耗材到挤出机）
2. 物理全速进料
3. 检测到 hw_switch_state == 3（挤出机有料）后停止
4. 等待 ams_status 变为 263（冲刷旧耗材）
5. 缓慢进料
6. 检测到 ams_status == 768（冲刷完成）后停止

退料按钮行为（主动模式）：
1. 等待 ams_status 变为 260（抽回耗材丝）
2. 物理退料
3. 等待 hw_switch_state 变为 2（挤出机无料）

装载按钮行为（主动模式）：
1. 先执行退料流程
2. 等待打印机完全空闲（ams_status 连续为 0）
3. 再执行进料流程

缓慢进料参数

主界面顶部可调：

| 参数 | 说明 | 默认 |
|------|------|------|
| 全速超时 | 全速进料超时（秒） | 180 |
| 脉冲 | 缓慢进料脉冲宽度（ms） | 30 |
| 间隔 | 缓慢进料间隔（ms） | 600 |

调试按钮：点「测试」运行 3 秒验证参数；点「保存」持久化到 NVS。

微动辅助送料

可选配置，默认关闭。需在网页打开「微动辅助送料」使能开关；使能后微动开关（GPIO7）电平有效时，ESP32 自动为当前通道送料。

| 参数 | 说明 | 默认 |
|------|------|------|
| GPIO | 微动开关 GPIO 编号（固定 GPIO7） | 7 |
| 使能 | 微动辅助送料总开关（网页复选框开关） | 关闭 |
| 有效电平 | 高有效 / 低有效（网页按钮切换，自动切换上/下拉） | 低有效 |

每次触发送料时长固定 500 ms、最小触发间隔固定 1000 ms（固件内置，网页不可配置）。

打印监控

点击主界面「打印监控」→ 实时查看所有 MQTT 字段。

字段变化高亮显示，用于调试换料流程。

固件升级（OTA）

1. 点击主界面「固件升级 (OTA)」
2. 选择编译好的 top_ams_pro_0x20000.bin
3. 点击「上传并升级」
4. 设备自动重启（约 30 秒）

首次烧录必须先擦除 Flash，详见「九、编译与烧录」。

恢复出厂设置

方法 1：长按 ESP32 上的 BOOT 按钮 10 秒以上

方法 2：主界面 → 清空 WiFi 配置 → 重新配网

常见问题

Q1：配网后找不到 ESP32？
ESP32 切换到 STA 模式后 IP 会变。查看串口日志里的 STA IP，或从路由器管理界面找设备。

Q2：打印机状态一直「未连接」？
检查打印机 IP / SN / Access Code 是否正确（区分大小写），以及打印机是否在同一局域网。

Q3：换料后打印不恢复？
被动模式的已知限制，需在打印机屏幕上手动点「继续」。如需全自动，切换主动模式。

Q4：主动模式弹 07FF-8007？
这是 G-code 通道换料的固件行为（「请确认料从喷嘴挤出」）。手动点「继续」即可。

Q5：主界面「挤出机」状态显示不对？
hw_switch_state 反映挤出机缺料检测开关的状态。有料 = 挤出机检测到耗材，无料 = 无耗材。

## 三、硬件接线

### DRV8833 电机驱动

每片 DRV8833 驱动 2 路直流电机，8 通道需要 4 片。

| 通道 | DRV8833 | 进料 GPIO | 退料 GPIO |
|------|---------|----------|----------|
| 1 | 片1-A | 2 | 3 |
| 2 | 片1-B | 10 | 6 |
| 3 | 片2-A | 5 | 4 |
| 4 | 片2-B | 8 | 9 |
| 5 | 片3-A | 0 | 1 |
| 6-8 | - | -1 | -1 |

### 电机控制逻辑

| 动作 | IN1 | IN2 |
|------|-----|-----|
| 正转（进料） | 1 | 0 |
| 反转（退料） | 0 | 1 |
| 停止 | 0 | 0 |

## 四、软件架构

### 任务结构

filament_uload_task 退料任务（ams_status == 260 触发）
filament_load_task 进料任务（ams_status == 261 触发）
filament_active_task 主动模式任务
filament_buffer_task 微动辅助送料

### 换料状态机

退料：
IDLE → ams_status == 260 → 物理退当前通道 → 完成

进料：
IDLE → ams_status == 261 → 全速进料
     → hw == 3 → 停止全速进料
     → ams_status == 263 → 缓慢进料
     → ams_status == 768 → 停止

### ams_status 对照表

| 值 | 含义 | ESP32 动作 |
|----|------|-----------|
| 0 | 空闲 | 等 |
| 258 | 加热喷嘴 | 等 |
| 259 | 切断耗材丝 | 等 |
| 260 | 抽回耗材丝 | 物理退料 |
| 261 | 送耗材到挤出机 | 物理进料 |
| 263 | 冲刷旧耗材 | 缓慢进料 |
| 768 | 冲刷完成 | 停止 |
| -1 | 未知 | 等 |

## 五、MQTT 通讯协议

本节参考 Top-AMS 项目的 MQTT 实现。

### 连接配置

| 参数 | 值 |
|------|-----|
| 协议 | MQTT over TLS |
| 端口 | 8883 |
| 用户名 | bblp |
| 密码 | 打印机访问码（8位数字） |
| TLS | 必须，自签名证书（跳过验证） |
| Keep-alive | 60s |

### 主题结构

| 主题 | 方向 | 用途 |
|------|------|------|
| device/{serial}/report | 打印机 → ESP32 | 状态上报（订阅） |
| device/{serial}/request | ESP32 → 打印机 | 控制命令（发布） |

### 状态上报字段

| JSON 字段 | 存储变量 | 用途 |
|-----------|---------|------|
| print.ams_status | ams_status | 换料流程状态 |
| print.hw_switch_state | hw_switch | 微动开关状态 |
| print.bed_target_temper | bed_target_temper | 热床温度/通道信号 |
| print.gcode_state | gcode_state | 打印状态 |
| print.nozzle_target_temper | nozzle_target_temper | 喷嘴目标温度 |

### 控制命令发布

ESP32 向 request 主题发布 JSON 命令：

{
  "print": {
    "sequence_id": "0",
    "command": "gcode_line",
    "param": "M620 S255\nT255\nM621 S255\n"
  }
}

### 热床温度信号机制

后处理 G-code 将热床目标温度设为 1-16 传递目标通道号（M140 S<通道号>）。ESP32 检测到 bed_target_temper 在 1-17 范围内时解释为通道选择，换料完成后恢复原始温度。

## 十一、两种模式对比

| 项目 | 被动模式 | 主动模式 |
|------|---------|---------|
| ESP32 发命令 | 否 | 是 |
| 读状态 | 是 | 是 |
| 物理进退料 | 是 | 是 |
| 需要开发者模式 | 否 | 是 |
| 手机 App | 可用 | 不可用 |
| 弹窗 | 有 | 无 |

### 主动模式的打印机要求

主动模式需要打印机开启**仅局域网模式 + 开发者模式**，否则 ESP32 通过 MQTT 发送的控制命令（M620、M621 等）会被打印机固件的授权控制系统（ACS）拦截。

| 开关 | 作用 |
|------|------|
| 仅局域网模式 | 打印机断开与拓竹云的连接，只保留本地 MQTT 服务 |
| 开发者模式 | 在仅局域网基础上，开放本地 MQTT 的写权限 |

**缺一不可**：

- 只开仅局域网，不开开发者模式 → MQTT 只能读，不能发控制命令
- 不开仅局域网，只开开发者模式 → 开发者模式本身就依赖仅局域网

⚠️ **开启这两个模式后，手机 App（Bambu Handy）将无法使用。** 这是拓竹固件的硬性设计，不是配置问题。

**原因**：2025 年 1 月固件更新后，拓竹引入授权控制系统（ACS）。仅局域网模式切断了与拓竹云的连接，Bambu Handy 无法再控制打印机。开发者模式则在此基础上进一步开放本地 MQTT 写权限。

**结论**：想在手机 App 和 ESP32 主动控制之间二选一，不能兼得。

- 想用手机 App → 打印机保持云端模式 → ESP32 只能走被动模式
- 想让 ESP32 主动控制 → 开仅局域网 + 开发者模式 → 手机 App 不可用
